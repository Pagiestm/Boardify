# Configuration Appwrite

Une base de données, un bucket et une clé d'API suffisent. Chaque collection a son identifiant dans `.env.local` (`NEXT_PUBLIC_APPWRITE_<NOM>_ID`).

## Projet

- **Plateformes** : une plateforme Web pour `localhost` et une pour le domaine de production.
- **Connexion** : e-mail et mot de passe, Google et GitHub dans _Auth → Settings_.
- **Clé d'API** (`NEXT_APPWRITE_KEY`) : `users.read`, `users.write`, `sessions.write`, `databases.read`, `databases.write`, `documents.read`, `documents.write`, `files.read`, `files.write`.
- **Bucket d'images** : tous les types de fichiers, 10 Mo maximum, permissions « All users » : Create, Read, Delete.

## Collections

Sauf mention contraire, les permissions sont « All users » : Create, Read, Update, Delete. Les identifiants (`workspaceId`, `taskId`, `memberId`…) sont des `string` de 36 caractères.

`ai_settings` n'a **aucune permission** : seul le serveur y accède avec la clé d'API (les clés des fournisseurs y sont chiffrées avec `AI_ENCRYPTION_KEY`).

## Index

Appwrite accepte les requêtes sur des attributs sans index : les index ci-dessus ne sont donc pas obligatoires, ils accélèrent les requêtes les plus fréquentes. Les index `unique` font exception : ils garantissent qu'une valeur n'existe qu'une fois (code d'invitation, jeton d'un formulaire…).

Si le volume de données grandit, ces index composés deviennent utiles :

| Collection     | Index composé                                               | Requête accélérée                                |
| -------------- | ----------------------------------------------------------- | ------------------------------------------------ |
| `time_entries` | `workspaceId, memberId, endedAt` ; `workspaceId, startedAt` | Chronomètre en cours ; rapport par période       |
| `reminders`    | `userId, sent, remindAt`                                    | Rappels échus, à chaque relevé des notifications |
| `poker_votes`  | `taskId, round`                                             | Votes du tour en cours                           |
